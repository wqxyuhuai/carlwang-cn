Create an interactive clickable website prototype for a personal creative hub called “Carl Wang”.

This is not a traditional portfolio only. It is a personal website that combines:
1. Public portfolio showcase
2. Personal project showcase
3. About / Contact
4. A protected owner-only Studio tab for content management and personal tools

Important:
- Do NOT create a public Resources page or Resources navigation item.
- Do NOT create a separate admin website.
- Use Scheme B: show a locked “Studio 🔒” tab in the main navigation.
- When clicking Studio, show a password verification modal or unlock screen.
- After verification, enter Studio Mode inside the same website.
- Make the prototype clickable and interactive: navigation, filters, project cards, detail pages, Studio tabs, edit buttons, upload panel, link manager, QR code modal, contact form states.
- Use placeholder content, but make it feel realistic.

Reference style:
Take inspiration from:
- Rafael Varona: artistic personal portfolio, motion/illustration energy, playful visual storytelling
- ForAI Design: premium creative studio feeling, selected works layout, clean but expressive typography
- Outpace Studios: bold hero, strong project presentation, dark modern studio aesthetic, sharp CTA sections

Do not copy these websites directly. Use them only as mood references.

Overall visual direction:
- Initial design can have some style, but do not over-polish it yet
- Dark premium background
- Large bold typography
- Subtle gradient lighting
- Slight playful motion/illustration feeling
- Clean project cards
- Designer portfolio + creative studio feeling
- Not too corporate, not too SaaS landing page
- Not childish, not overly cyberpunk
- Use grayscale / dark base with limited accent colors
- Desktop-first layout, 1440px wide
